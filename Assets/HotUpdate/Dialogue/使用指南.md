# 对话系统使用指南

## 快速开始

```csharp
using QFramework;
using HotUpdate.Dialogue.Commands;

// 发送命令启动对话
this.SendCommand(new StartDialogueCommand("test_dialogue"));
```

---

## 使用示例

### 1. NPC对话

```csharp
using QFramework;
using UnityEngine;

public class NPC : MonoBehaviour
{
    public string dialogueId = "npc_talk";

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Player"))
        {
            this.SendCommand(new StartDialogueCommand(dialogueId));
        }
    }
}
```

### 2. 交互对话

```csharp
using QFramework;
using UnityEngine;

public class NPCInteraction : MonoBehaviour
{
    [SerializeField] private string dialogueId = "npc_talk";
    [SerializeField] private GameObject promptUI;

    private bool isPlayerNearby = false;

    private void Update()
    {
        if (promptUI != null)
            promptUI.SetActive(isPlayerNearby);

        if (isPlayerNearby && Input.GetKeyDown(KeyCode.E))
        {
            this.SendCommand(new StartDialogueCommand(dialogueId));
        }
    }

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Player")) isPlayerNearby = true;
    }

    private void OnTriggerExit2D(Collider2D other)
    {
        if (other.CompareTag("Player")) isPlayerNearby = false;
    }
}
```

## 监听对话事件

```csharp
using HotUpdate.Dialogue.System;
using QFramework;

public class YourGameScript : MonoBehaviour, IController
{
    private DialogueSystem dialogueSystem;

    void Start()
    {
        dialogueSystem = this.GetSystem<DialogueSystem>();
        dialogueSystem.OnDialogueEnd.AddListener(OnDialogueEnd);
    }

    void OnDialogueEnd(string dialogueId)
    {
        // 处理对话完成
    }

    void OnDestroy()
    {
        dialogueSystem.OnDialogueEnd.RemoveListener(OnDialogueEnd);
    }

    public IArchitecture GetArchitecture()
    {
        return TheWorstGameInHistory.Interface;
    }
}
```

## 节点事件

节点可以在开始时触发事件，例如播放语音、触发自定义事件等。

### JSON 配置示例

```json
{
  "nodes": {
    "node_1": {
      "nodeId": "node_1",
      "speaker": "NPC",
      "textKey": "npc_hello",
      "events": [
        {
          "type": "PlayVoice",
          "value": "Voice/NPC/Hello_01"
        },
        {
          "type": "CustomEvent",
          "value": "OnNPCStartTalking"
        }
      ],
      "nextNodeId": "node_2"
    }
  }
}
```

### 支持的事件类型

- **PlayVoice**: 播放语音，`value` 为语音资源的 Addressable 地址
- **CustomEvent**: 自定义事件，`value` 为事件名称（可扩展）

### 对话级事件

对话开始和结束时也可以触发事件：

```json
{
  "config": {
    "events": {
      "onStart": [
        {
          "type": "CustomEvent",
          "value": "OnDialogueStart"
        }
      ],
      "onEnd": [
        {
          "type": "CustomEvent",
          "value": "OnDialogueEnd"
        }
      ]
    }
  }
}
```

## 架构

```
发送命令 → this.SendCommand(new StartDialogueCommand("dialogue_id"))
              ↓
StartDialogueCommand.OnExecute()
              ↓
创建 DialogueController 实例
              ↓
对话运行，完成后自动清理
```

使用 QFramework Command 模式，简单直接。
